n8n Gmail Local

A personal-use OAuth client operated by its owner for the owner's own automation (n8n workflows and rclone-based file sync with Google Drive). It is not offered to the public and is used by fewer than 100 people known personally to the owner.

Privacy Policy

Last updated: 2026-10-14

  • Data accessed: Only the Google account data the signed-in user explicitly authorizes (e.g. Gmail messages, Google Drive files) and only for the user's own workflows.
  • Use: Data is used solely to perform the automation the user configured (e.g. downloading recordings from Drive, processing them, and uploading the resulting documents back to the user's Drive).
  • Storage: Data is processed on computers controlled by the owner. OAuth tokens are stored locally on those computers.
  • Sharing: Google user data is never sold, never used for advertising, and never shared with third parties except service providers the owner uses to run the same personal workflow.
  • Google API Services User Data Policy: Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revocation: Access can be revoked at any time at myaccount.google.com/permissions.

プライバシーポリシー（日本語）

本アプリは所有者本人が自分の自動化（n8n・rclone による Google Drive 同期）のためだけに使う個人用 OAuth クライアントであり、一般には提供していない。取得するデータはユーザーが許可した範囲に限り、設定された処理にのみ使用する。データは所有者の管理するコンピュータ上で処理し、販売・広告利用・第三者提供は行わない。アクセス権は上記リンクからいつでも取り消せる。
